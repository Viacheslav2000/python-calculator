# python-calculator
Konsolen-Taschenrechner in Python
Ein kleines, aber feines Taschenrechner-Skript, das ich als solide Basis für zukünftige Programmierprojekte geschrieben habe. Das Tool läuft direkt über die Kommandozeile und ist darauf ausgelegt, sauber und stabil zu funktionieren.
🚀 Was das Programm kann
Grundrechenarten: Addition, Subtraktion, Multiplikation und Division.
Fehlerbehandlung: Fängt den Versuch, durch Null zu teilen, ab und gibt eine entsprechende Warnmeldung aus, anstatt abzustürzen.
Schleifen-Funktion: Nach einer erfolgreichen (oder abgefangenen) Rechnung startet das Programm automatisch von vorn, sodass man direkt weiterrechnen kann, ohne es neu starten zu müssen.
Einfache Bedienung: Klare Textführung direkt im Terminal.
